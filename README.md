# Estado del proyecto – Superautos Carballo

## Páginas hechas

- **Inicio** (`index.html`) – Hero con carrusel de vehículos destacados.
- **Catálogo** (`catalogo.html`) – Grid con los coches disponibles.
- **Servicios** (`servicios.html`) – Secciones de venta, mantenimiento y posventa.
- **Recambios** (`recambios.html`) – Hero + formulario de solicitud de recambios.
- **Contacto** (`contacto.html`) – Formulario de contacto.
- **Ficha de vehículo** (`ficha_vehiculo.html`) – Página individual de cada coche.
- **Prueba de conducción** (`proba_conduccion.html`) – Formulario en varios pasos.
- **Política de privacidad** (`privacidad.html`) – Texto legal básico.
- **404** (`404.html`) – Página de error personalizada.
